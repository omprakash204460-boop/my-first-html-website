# my-first-html-website

## About the Project
This is my first beginner-level website project created using HTML. It represents a simple personal website and demonstrates the use of semantic HTML elements.

## Features
- Home section with a welcome message
- About Me section
- Services section
- Important Notes sidebar
- Contact section
- Footer with copyright information
- Navigation links to different sections of the page

## Technologies Used
- HTML5

## HTML Concepts Learned
- Basic HTML document structure
- Semantic HTML tags
- Headings and paragraphs
- Navigation links using anchor tags
- Sections and articles
- Header, main, aside, and footer elements
- Using IDs for internal navigation

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
